# تسجيلات شاشة TMRKZ

تسجيلات للشاشة أثناء العمل على التطبيق، بدون صوت، لاستخدامها لاحقاً في التدريب.

| التسجيل | الملف |
|---|---|
| استوديو التدفقات: التعرف عليه وأول خطوة (نص على الشاشة) | `studio/01-introduction.mp4` |
| مسار الموافقات من الصفر، الخطوة 1: الشاشة فارغة بعد حذف كل التدفقات، مع صورها | `studio/from-scratch/01-*` |
| مسار الموافقات من الصفر، الخطوة 2: الأسماء الواضحة، مع صورها | `studio/from-scratch/02-*` |
| مسار الموافقات من الصفر، الخطوة 3: حذف أنواع الطلبات القديمة، مع صورها | `studio/from-scratch/03-*` |
| مسار الموافقات من الصفر، الخطوة 4: نافذة نوع الطلب الجديدة، مع صورها | `studio/from-scratch/04-*` |
| مسار الموافقات من الصفر، الخطوة 5: إضافة نوع «طلب صلاحيات»، مع صورها | `studio/from-scratch/05-*` |
| رسم مسار «طلب صلاحيات»: بطاقة المراجعة، الاعتماد النهائي، النهاية، ثم التجربة، مع صورها | `studio/from-scratch/06-*` إلى `09-*` (صُوّرت 06 إلى 09 قبل إزالة المهلة، فتظهر فيها) |
| طلب الصلاحيات بلا مهلة، والصلاحيات المعروضة للطلب، مع صورها | `studio/from-scratch/10-*` و`11-*` |
| جولة في كل ما تغير في الاستوديو، مع صورتها | `studio/from-scratch/12-*` |

التسجيل يعمل أثناء العمل على الشاشة ويتوقف عند التوقف، وتُجمع الأجزاء في ملف واحد بالأداة `tools/live-recorder.mjs`.
