**الحالة:**
- النموذج للمراجعة فقط، ولم يُدمج في التطبيق. لن يُدمج قبل موافقة المالك.
- كل البيانات في الصور وهمية.
- لا تحوي الحزمة كلمات مرور، ولا بيانات أشخاص، ولا مواقع حقيقية.
