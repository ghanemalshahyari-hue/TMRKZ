# السيناريوهات

سيناريوهات اختبار الإنتاج التي يحددها المالك، وتُبنى وتُنفَّذ بعد أن ينتهي من مراجعة الصفحات. لكل سيناريو ملف واحد:
ما المطلوب، وما يفعله النظام الآن، وخطوات التجربة، والنتيجة المتوقعة.
