# دليل البدء السريع — مركز إدارة تمركز

## الوصول إلى مركز الإدارة

1. افتح عنوان تمركز في المتصفح (مثال: `https://10.1.2.3:8088` أو العنوان المعتمد).
2. سجّل الدخول بحساب مدير النظام (`admin` أو حسابك المؤسسي).
3. من شريط التنقل العلوي اختر **إعدادات النظام**.
4. مرِّر إلى قسم **مركز إدارة النظام** (يظهر لأصحاب صلاحية CONFIGURE فقط).

---

## أقسام مركز الإدارة

### 1. حالة النظام

يعرض:
- إصدار التطبيق ووقت الخادم
- حالة قاعدة البيانات (متصلة / غير متصلة)
- إصدار المخطط (رقم آخر ترحيل Flyway)
- عدد الوحدات والأشخاص والطلبات والمرافق
- عدد حزم الخرائط المثبتة

### 2. شهادة HTTPS

- إذا كان HTTPS مهيأً: يعرض الموضوع والمُصدر وتاريخ الانتهاء والأسماء البديلة (SAN).
- إذا لم يُهيَّأ: يعرض خطوات التفعيل عبر سطر الأوامر:
  ```
  sh ops/tls/make-csr.sh        # إنشاء طلب توقيع
  sh ops/tls/install-cert.sh    # تثبيت الشهادة المصدرة
  sh ops/tls/enable.sh          # تفعيل HTTPS
  ```

### 3. التضمين في مواقع أخرى (Embedding)

- بشكل افتراضي: التضمين في إطار (iframe) محظور.
- لإضافة أصل مسموح: اكتب عنوان HTTPS بالصيغة `https://host` أو `https://host:port` ثم اضغط **إضافة**.
- اضغط **حفظ أصول التضمين** لتطبيق التغيير.
- لإزالة أصل: اضغط **إزالة** بجانبه ثم احفظ.

### 4. النسخ الاحتياطية

- يعرض عدد النسخ المحفوظة ومسار المجلد على الخادم.
- الأوامر المرجعية:
  ```
  sh ops/tmrkzctl.sh backup              # إنشاء نسخة
  sh ops/verify-restore.sh               # التحقق من النسخة
  sh ops/tmrkzctl.sh rollback <مجلد>     # الاستعادة
  ```

### 5. أوامر الطوارئ

مرجع سريع لأوامر التشخيص والاسترداد على الخادم:

| الغرض | الأمر |
|-------|-------|
| التشخيص | `sh ops/tmrkzctl.sh doctor` |
| الحالة | `sh ops/tmrkzctl.sh status` |
| التحقق | `sh ops/tmrkzctl.sh verify` |
| الإعداد | `sh ops/tmrkzctl.sh setup` |
| التحديث | `sh ops/tmrkzctl.sh update <bundle.tar.gz>` |
| النسخ الاحتياطي | `sh ops/tmrkzctl.sh backup` |
| الاستعادة | `sh ops/tmrkzctl.sh rollback <backup-dir>` |
| جرد التثبيت | `sh ops/tmrkzctl.sh inventory` |

## إعدادات التكامل (أعلى مركز الإدارة)

### الدليل المؤسسي (LDAP)

1. في قسم **الهوية والدخول** ← **إعدادات التكامل — الدليل المؤسسي (LDAP)**:
   - اكتب عنوان الخادم (الاسم الذي صدرت له الشهادة).
   - اختر وضع التأمين: LDAPS (636) أو StartTLS (389).
   - اكتب نطاق الدخول وقاعدة البحث (Base DN).
   - حساب الخدمة اختياري: إذا لم يكن متاحاً، يُستخدم ربط مباشر.
2. الصق شهادة الجهة المصدرة (CA) بصيغة PEM إن كانت من جهة داخلية.
3. اضغط **اختبار الاتصال** مع اسم مستخدم وكلمة مرور للتجربة.
4. إذا نجح الاختبار: اضغط **حفظ** ← يسري فوراً بلا إعادة تشغيل.

### الدخول الآلي (Keycloak)

1. في قسم **إعدادات التكامل — الدخول الآلي (Keycloak)**:
   - اكتب عنوان خادم Keycloak والمجال (Realm) ومعرّف العميل وسره.
2. اضغط **اختبار الاتصال** ثم **حفظ**.

### المساعد الذكي

1. في قسم **المساعد الذكي**: فعّل المساعد واكتب عنوان خادم النموذج واسم النموذج.
2. اضغط **اختبار الاتصال** للتحقق من استجابة الخادم.

---

## ملاحظات

- كل التغييرات في إعدادات التكامل تسري فوراً بلا إعادة تشغيل.
- الأسرار (كلمات المرور والمفاتيح) تُشفَّر على الخادم ولا تُعرض بعد الحفظ.
- الحقول الإضافية في إعدادات الدليل (الرتبة، المنصب، معرّف الوحدة…) كلها اختيارية.
