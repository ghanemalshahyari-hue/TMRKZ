# MOVER administrative concept workspace

This repository holds self-contained, fictional administrative facilities UI concepts and an implementation handoff. It is not a production backend or a military deployment planning system.

## Rebuild

The original five concepts are generated by `python build_concepts.py`.
The unified prototype and Claude handoff are generated by `python build_unified.py`.
Run the unified builder last so that `dist/index.html` remains the unified prototype.
`dist/concepts.html` preserves the previous five-concept gallery.

The builders use the checked-in Leaflet assets, font, regional SVG basemap and their licenses. No dependency installation is needed to generate the HTML. The geographic data snapshot is illustrative, and all named facilities and requests are fictional.

## Deliverables

- `dist/index.html`, `dist/prototype.html`, `dist/06-unified.html`: unified standalone prototype.
- `dist/mover-claude-handoff.zip`: prototype, requirements, decisions, architecture, data model, API behavior, acceptance tests, source references and verification notes.
- `handoff/`: editable authoritative specification sources.
- `unified/`: editable UI sources.

See `handoff/START_HERE.md` for user-facing instructions and boundaries.
